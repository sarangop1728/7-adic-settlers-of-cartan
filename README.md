# 7-adic Galois representations of elliptic curves over the rationals via Kummer descent

Santiago Arango-Piñeros and David Zureick-Brown

This repository holds the paper and the [Magma](http://magma.maths.usyd.edu.au/magma/)
code that verifies its computations. Both come from one literate file,
[`7-adic-settlers-of-cartan.org`](7-adic-settlers-of-cartan.org): the paper's LaTeX is
in it verbatim, section by section, and each statement that involves a
computation is followed by the Magma code that checks it.

- **Read the paper with its code:** <https://sarangop1728.github.io/7-adic-settlers-of-cartan/>
  (each check is a folded box under its statement, with the output it prints).
- **The paper:** [`7-adic-settlers.tex`](7-adic-settlers.tex), the arXiv source,
  and [`docs/7-adic-settlers.pdf`](docs/7-adic-settlers.pdf).
- **The code:** the six files in [`magma/`](magma).

## The result

We show that the two modular curves of level 49 and genus 9 left open by the
work of Rouse, Sutherland and Zureick-Brown, and of Furio and Lombardo, have no
non-CM rational points. With the theorem of Furio and Lombardo on
X<sub>ns</sub><sup>+</sup>(49), this completes the classification of the 7-adic
images of Galois of non-CM elliptic curves over Q. The proof is a Kummer
descent on the superelliptic equations F(x,y) = k w<sup>7</sup>.

## Running the code

Each file in `magma/` runs on its own (Magma V2.28; any recent version should
do) and prints a report: for each statement of the paper it checks, the number
and title of the statement, the objects that can be compared with the paper,
and `verified`. In the code, each claim of the paper is a comment followed by
the `assert` statements that verify it; a failed `assert` stops Magma with a
nonzero exit code and points at the line just below the claim.

```
magma -b magma/descent.m < /dev/null
```

| file | checks | time |
|---|---|---|
| [`descent.m`](magma/descent.m) | the descent run end to end: the Selmer sets, the local sieve on the 49 twists, the twelve rational points they carry, the 7-adic step, the Klein quartic, and Table 1 | 30 s |
| [`equations.m`](magma/equations.m) | Sections 1 and 2: the field, the forms, the groups G<sup>♯</sup>(49), the cusps | 1 s |
| [`kummer.m`](magma/kummer.m) | Section 3: Table 3, the trace form, the twists of the Fermat septic | 25 s |
| [`klein.m`](magma/klein.m) | Section 4: the quotient map, Klein's identity, Hurwitz's theorem | 1 s |
| [`theorem-1.m`](magma/theorem-1.m) | Section 5: κ, Σ, the 7-adic step, Theorem 1, the twists of the Klein quartic | 20 s |
| [`theorem-2.m`](magma/theorem-2.m) | Section 6: the Frobenius criterion, Table 4, Theorem 2 | 2 s |

## Building

Only the org file and `tools/` are edited by hand; everything else is
generated by `make`:

| target | output |
|---|---|
| `make tangle` | `7-adic-settlers.tex` and `magma/*.m`, from the org file |
| `make pdf` | `build/7-adic-settlers.pdf`; fails on undefined references or citations |
| `make check` | runs the six Magma files (in parallel with `make -j`), and checks the statement numbers they print against the paper's `.aux` |
| `make html` | the web version in `docs/` |
| `make all` | all of the above |
| `make sync` | copies the Overleaf version of the paper into the org file |
| `make check-sync` | the tangled paper is byte-identical to the Overleaf version |

Building needs Emacs (29 or later) with the packages `htmlize` and
`magma-mode` from MELPA, a TeX distribution with `latexmk`, `amsrefs` and
`tikz-cd`, `pdftocairo` (Poppler), Python 3, and Magma. Reading the web
version or running a Magma file needs none of them but Magma.

The web version uses the stylesheets in `tools/assets/`. Its LaTeX is converted
by `tools/tex2html.py`, which takes every number (sections, statements,
equations, items, tables, citation labels) from the `.aux` file of the
compiled paper, so that the page and the PDF cannot disagree.
